# 12 inch Baguette Meal Finder

Free, mobile-friendly meal finder with instant budget and preference matching, menu photos, and a single ordering CTA.

## Run locally

From the repository directory:

```bash
python -m http.server 8000 --directory dist
```

Open http://localhost:8000.

## Deploy on Netlify

- Build command: leave empty
- Publish directory: `dist`

Prices are starting-price estimates checked on 8 October 2026; confirm the final total and availability with the restaurant. Menu photos are from https://12inchbaguette.africa/.
